# Code of conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, roast teams and kickers, not people. Harassment,
slurs and personal attacks are not welcome in issues, PRs or the Discord.

Report problems privately to the maintainer through
[GitHub security advisories](https://github.com/moudlajs/jinx/security/advisories/new)
or a direct message to @moudlajs. Reports are handled confidentially.
